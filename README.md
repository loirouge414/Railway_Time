# Railway_Time
끄적끄적 개발용, java로 만드는 개발 겸 취미용

아직 확실한 목표 X

Java를 주로 이용, 우선 Mac용 응용 프로그램을 만들 것

개발 단계
1. Java를 이용하여 지하철, 전철, 기차 등의 철도 노선도 만들기
2. 이후 각 역의 시간표, 역 간 거리, 역에 정차하는 운행 등급, 환승 가능 노선 등 기능 추가

세부 단계
1. 프로그램 실행 시 프로그램 대표 화면 1~2초 띄우기

2. 이후 국가 선택 -> 보고 싶은 역이나 노선도 선택하는 국가 선택
    이때, 사각형이지만 각이 둥근 모양의 버튼으로 만들기
    일단 1920 * 1080 화면 기준으로 화면 가운데에서 왼쪽, 오른쪽에 2개의 버튼을 배치
    우선 한국의 노선도를 기준으로 만들거고, 왼쪽 버튼을 눌렀을 때 한국 지역으로 넘어가기

3. 국가 선택 시, 해당 국가의 지역 선택 창으로 넘어가기

4. 지역 선택 시, 해당 지역에서 운행하는 노선, 해당 지역의 역을 선택하는 창으로 넘어가기
    이때, 2번과 같이 노선과 역을 선택하는 화면은 버튼을 이용하여 넘어가기
    노선을 왼쪽 버튼, 역을 오른쪽 버튼으로 할당하기

    4-a. 노선 버튼을 선택할 시, 기존에 입력되었던 노선들 목록을 세로줄로 차례대로 배치
        목록 중, 해당 노선을 클릭할 시 해당 노선으로 넘어가기
        해당 화면 오른쪽 위에 추가하기, 수정하기 버튼 추가
        추가하기 버튼 : 새로운 노선을 추가하기
        수정하기 버튼 : 기존 노선을 수정하기

        4-a.1. 추가/수정 버튼을 눌렀을 시
            추가할 노선 이름, 노선의 회사, 기점역, 종점역, 운행 형태를 서두에 정리
            그 밑으로는 역 목록 추가
                각 역마다 한국어와 영어 이름 (한국 지역), 일본 이름 (일본 지역, 추후 추가 예정)
                역 번호, 역의 승강장 형태, 정차/통과하는 노선의 운행 형태, 환승 가능 노선 등을 추가/수정

    4-b. 역 버튼을 선택할 시, 한국어 기준 가나다순으로 정렬
        정렬된 역 목록은 가운데 상단 검색창 밑에 정렬
        가운데 상단 검색창으로 입력된 역을 검색하여 찾을 수 있도록 함
        4-b.1. 역 선택 시 역에 대한 상세 정보 확인 가능
                상세 정보 : 한국어와 영어 이름 (한국 지역), + 일본 이름 (일본 지역, 추후 추가 예정)
                    역 번호, 역의 승강장 형태, 정차/통과하는 노선의 운행 형태, 환승 가능 노선, 정차 시간, 운행 행선지 등

추가, 수정 단계는 관리자 권한을 받아야 함
    관리자 권한 : 미리 입력받은 관리자 권한이 부여된 ID, PW를 입력하고 들어감
        관리자가 아닌 사람들이 추가, 수정할 때는 ID, PW가 아닌 이름과 추가/수정할 노선/역의 이름, 추가/수정할 부분을 명시하게끔 편집을 관리자에게 요청함
        이후 관리자가 이를 확인하고 최종 변경 확인/거절

각 버튼들은 색상을 추후에 넣을 예정, 색상과 사진 모두 넣을 예정이므로, 이에 유의하여 버튼 크기, 디자인 선택
